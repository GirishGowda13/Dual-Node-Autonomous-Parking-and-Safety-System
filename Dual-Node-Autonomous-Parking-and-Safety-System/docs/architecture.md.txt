# System Architecture

## Overview

The Dual-Node Autonomous Parking and Safety System is a distributed embedded system consisting of two independent PIC16F877A-based nodes.

- **Node 1:** Autonomous Parking Controller
- **Node 2:** Safety Monitoring Controller
- **Communication:** UART between Node 1 and Node 2

The two nodes operate independently but exchange safety information during operation.
