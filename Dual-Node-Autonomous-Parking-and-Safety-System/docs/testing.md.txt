# Testing and Validation

## Overview

The Dual-Node Autonomous Parking and Safety System was tested at both the individual-node level and at the complete system level.

Testing was performed to verify sensor operation, actuator control, autonomous parking, UART communication, and safety-state handling.

---

| Front ultrasonic sensor | Detects front obstacles                   | PASS |
| Left ultrasonic sensor  | Detects left-side distance                | PASS |
| Rear ultrasonic sensor  | Detects rear obstacles                    | PASS |
| Right ultrasonic sensor | Detects right-side distance               | PASS |
| Directional LEDs        | Indicate corresponding direction/obstacle | PASS |
| Buzzer                  | Activates during warning conditions       | PASS |

| Test                    | Expected Result            |Result|
|-------------------------|----------------------------|------|
| SAFE transmission       | Node 2 sends `S`           | PASS |
| WARNING transmission    | Node 2 sends `W`           | PASS |
| CRITICAL transmission   | Node 2 sends `C`           | PASS |
| Node 1 receives SAFE    | Normal operation continues | PASS |
| Node 1 receives WARNING | Warning state is activated | PASS |
